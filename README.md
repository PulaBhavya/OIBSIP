Projects
1. Voice Assistant

Description:

A Python voice assistant that responds to user commands. Features include greetings, telling the time/date, web searches, and simple responses.

Key Concepts:

* Speech Recognition using Speech_recognition
* Text-to-Speech using pyttsx3
* Web automation with webbrowser
* Error handling and user-friendly interaction
  
Run Instructions:

  bash 
  
    pip install pyttsx3 speechrecognition pyaudio
    python voiceassistant.py

Future Enhancements:
* Advanced natural language processing (NLP)
* Email, reminders, and smart home integration

2. BMI Calculator ⚖️
   
Description:

A BMI (Body Mass Index) calculator that takes weight and height from the user, calculates BMI, and classifies health status.

Key Concepts:

* Python arithmetic and conditionals
* Input validation
  
Run Instructions (Command-Line):

  bash
  
    python BMIcalculator.py
    
Advanced Features:

* GUI with input fields and result display
* Historical BMI data storage and visualization

3. Random Password Generator 🔒
   
Description:

Generates secure random passwords based on user-selected criteria like length, letters, numbers, and symbols.

Key Concepts:

* Randomization with Python’s random module
* String manipulation and input validation
  
Run Instructions (Command-Line):

  bash
  
    python GeneratePsw.py
    
Advanced Features:
* Tkinter GUI
* Copy-to-clipboard functionality
* Password strength indicator
